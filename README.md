# kazu-pon-assets

かずぽん（Kazu-pon）ブランドの systeme.io Raw HTML ページ・レクチャーに埋め込む画像・フォント等の静的アセットを公開ホスティングするためのリポジトリ。

- 管理元・実装の詳細：`ClaudeCode/2b_Member/Systeme_Kazu-pon`（プライベートリポジトリ）
- 参照方法：jsDelivr CDN経由（`https://cdn.jsdelivr.net/gh/Kazori/kazu-pon-assets@main/{path}`）を推奨。`raw.githubusercontent.com`でも参照可
- ディレクトリ構成：`{コース名またはページ名}/{アセットID}.{拡張子}`（例：`post-05/FA_5_001.png`）
